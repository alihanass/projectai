Actions & Transition Model

Exploiting an unpatched vulnerability edge (e.g., Phishing, SQLi, Pass-the-Hash) transitions the attacker to the adjacent host.

Path Cost g(n)

Exploit difficulty score per hop (1–6). Lower cost = easier, higher-risk attack vector.

Admissible estimated minimum exploit effort remaining to reach the Core Database (h(Goal) = 0).
